# 顾客性格差异测试用例

第三阶段测试目标：确认同样的经营系统下，6 类顾客在正确话术、错误话术、购买商品偏好和耐心轮数上有明显差异。

## 社恐内向型

正确话术：
不用急，我简单介绍一下，拿铁口感温和。

错误话术：
强烈推荐！大家都买，你必须试试！

预期：
正确话术会提升购买欲望，更偏向拿铁、美式等温和基础商品；错误话术会明显扣分。

## 挑剔达人型

正确话术：
这款手冲酸度明显，香气更干净，适合喜欢层次感的人。

错误话术：
都差不多，随便点一个就行。

预期：
正确话术会提升购买欲望，更偏向蓝山手冲、美式等咖啡标签商品；错误话术会明显扣分。

## 文艺青年型

正确话术：
这杯手冲有一点果香，适合坐下来慢慢喝。

错误话术：
这个便宜，快点买。

预期：
正确话术会提升购买欲望，更偏向蓝山手冲、提拉米苏等 story/art/relax 商品；错误话术会扣分。

## 社牛自来熟型

正确话术：
今天很多熟客都点拿铁，我觉得你也会喜欢。

错误话术：
随便，你自己看。

预期：
正确话术会提升购买欲望，更偏向 popular/sweet/dessert 商品；错误话术会扣分。

## 赶时间上班族

正确话术：
美式最快，马上可以打包带走。

错误话术：
你可以慢慢看看，我给你讲一下每款的故事。

预期：
正确话术会快速促成决策，更偏向美式、牛角包等 fast/takeaway 商品；错误话术会扣分，并且该顾客耐心较低。

## 纠结选择困难型

正确话术：
我建议你直接选拿铁，温和、不容易踩雷。

错误话术：
都可以，看你自己。

预期：
正确话术会提升购买欲望，更偏向 popular/mild/comfort 商品；错误话术会扣分，且需要明确推荐。
